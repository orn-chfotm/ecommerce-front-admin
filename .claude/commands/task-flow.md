요청: $ARGUMENTS

`.claude/rules/workflow.md`의 "규모별 적용" 표를 기준으로 처리한다.

1. 요청이 닿는 FSD 레이어와 변경 대상을 read-only로 파악한다.
2. 표에서 작업 유형을 고르고, 그렇게 분류한 근거를 한 줄로 밝힌다.
3. 해당 행의 첫 agent를 호출한다.
4. agent 산출물을 그대로 사용자에게 제시한다.
5. 승인 게이트가 있으면 거기서 **멈추고** 승인 요청 형식으로 사용자 확인을 받는다.

먼저 아래를 출력한 뒤 시작한다.

```md
## 작업 분류

- 요청 요약:
- 영향 레이어:
- 작업 유형:
- 분류 근거:
- 호출할 agent 순서:
- 승인 게이트:
```

## [금지사항]

- 분류를 건너뛰고 바로 구현을 시작하지 않는다.
- 승인 게이트가 있는 작업에서 사용자 확인 없이 다음 역할로 넘어가지 않는다.
- 작업을 실제보다 작은 유형으로 분류해 승인 게이트를 피하지 않는다.
