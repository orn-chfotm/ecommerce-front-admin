# 프론트엔드 검증

코드를 수정하지 않고 프론트엔드 변경을 검증한 뒤 결과를 보고한다.

## 실행 순서

1. `npm run lint`를 실행한다.
2. lint가 통과하면 `npm run build`를 실행한다. lint가 실패하거나 실행되지 못했으면 build를 실행하지 않고 사유를 기록한다.
3. 아래 형식으로 결과를 보고한다.

## 출력 형식

```md
## 검증 결과

- lint: 통과 / 실패 / 미실행
- lint 실패 항목: (파일:라인 — 규칙)
- build: 통과 / 실패 / 미실행
- build 실패 항목:
- 미실행 사유:
```

## [금지사항]

- 실패 항목을 요약에서 빼거나 "대부분 통과" 같은 표현으로 완화하지 않는다.
- 이 명령에서 코드를 수정하지 않는다. 검증과 보고만 한다.
- 실행하지 못한 명령을 통과로 적지 않는다. 실행 실패 사유를 그대로 적는다.
